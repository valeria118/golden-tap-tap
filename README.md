# 🪙 Coin Clicker — Golden Tap

> Tap the coin. Get rich. Build your coin empire!

Весёлый idle-кликер в одном HTML-файле: тапай золотую монету, покупай улучшения, играй в казино, выполняй квесты и открывай достижения. Без зависимостей, без сборки — просто открой `index.html` в браузере.

---

## 🎮 Gameplay

- **👆 Тапай монету** — зарабатывай монеты, лови критические клики (x10!)
- **🏗️ Покупай улучшения** — от рабочего до галактического банка: 9 уровней пассивного дохода
- **🌟 Престиж** — сбрось прогресс и получи постоянный множитель к доходу
- **💤 Офлайн-доход** — возвращайся и забирай накопленное (до 8 часов)
- **🎁 Ежедневный бонус** — заходи каждый день, серия увеличивает награду

## 🎰 Казино

- **🪙 Монетка удачи** — орёл или решка, ставка x2
- **🎰 Слоты** — три в ряд = ставка x10
- **🎡 Колесо фортуны** — множители от x0 до x5

## 🎯 Квесты и события

- **14 квестов** с полосой прогресса и наградами
- **14 достижений** — каждое даёт бонус к доходу
- **🔐 Босс-сейф** — прокликай сейф за 12 секунд и получи джекпот
- **✨ Золотая монета** — лови её и получи бонус или доход x7 на 30 секунд
- **😴 Живые рабочие** — уходят на перерыв и устают (авто-доход проседает)

## 🎨 Кастомизация

- 7 монет: от золотой до галактики
- 5 фонов: ночь, закат, лес, океан, космос

## ✨ Features

- Всё в **одном HTML-файле** — vanilla JS, ноль зависимостей
- Адаптивная вёрстка — телефон, планшет, ПК
- Поддержка PWA-манифеста (можно добавить на главный экран)
- Вибрация и звуки на мобильных (отключаемые)
- Сохранение в `localStorage` — прогресс не потеряется
- Плавный анимированный счётчик монет

## 🚀 Запуск

Просто открой `index.html` в браузере. Или через локальный сервер:

```bash
# Python
python -m http.server 8000

# Node
npx serve .
```

Затем открой `http://localhost:8000`.

## 🛠️ Технологии

- HTML5 + CSS3 (flexbox, grid, backdrop-filter, анимации)
- Vanilla JavaScript
- Web Audio API (звуки)
- localStorage (сохранения)
